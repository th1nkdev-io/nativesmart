# Nativesmart Kits

Kits are product-oriented bundles built on top of the core mobile libraries.

They are not separate SaaS products. They are reusable production accelerators for Th1nkdev projects and future premium offers.

## Kit Tiers

- Priority 1: `fintech`, `mobile-money`, `marketplace`, `offline-first`
- Priority 2: `delivery`, `saas`, `public-services`, `ecommerce`

## Standard Kit Structure

```txt
components/
screens/
flows/
mock-data/
adapters/
docs/
tests/
README.md
```

## Commercial Mapping

- Free: base tokens, base UI components, simple starters.
- Pro: business components and priority kits.
- Enterprise: private components, white-label branding, private registry, support and integration.
