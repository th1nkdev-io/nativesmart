# Showcase runtime

Framework-neutral code shared by the Nativesmart Lab shell and every renderer playground:

- `protocol.ts`: render requests and messages exchanged through `postMessage`, and their URL form;
- `theme.ts`: applies a brand theme, color mode and direction to a document from the tokens;
- `variations.ts`: default props and the variation matrix derived from a component contract.

See [Nativesmart Lab](../../apps/showcase/README.md).
