# React Native + NativeWind playground

Planned playground app for [`@nativesmart/react-native-nativewind`](../../../packages/mobile/react-native-nativewind). Nothing is implemented yet.

Expo playground configured with NativeWind and the shared Tailwind preset.

The playground displays every component, variant and state, with live theme, brand, density and
direction switching. See [Platforms](../../../docs/platforms.md).
