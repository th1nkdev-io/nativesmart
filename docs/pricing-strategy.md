# Pricing Strategy

This document is a planning model, not a final price list.

## Free Core

Purpose: adoption and internal standardization.

Includes:

- base tokens
- base React Native components
- base Flutter widgets
- simple starters
- public docs

## Pro Kits

Purpose: paid accelerators for recurring product categories.

Includes:

- business components
- priority kits
- premium starters
- advanced docs
- implementation recipes

## Enterprise License

Purpose: private client delivery and long-term support.

Includes:

- private registry access
- private components
- custom branding
- API integration support
- white-label theme packs
- migration support
- priority fixes
- training
- maintenance subscription

## Add-on Services

- setup client
- custom design system
- integration API
- team training
- monthly maintenance
- SLA-backed support
