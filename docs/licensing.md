# Licensing

Nativesmart should support internal, pro and enterprise licensing without changing the technical foundation.

## Internal License

Used by Th1nkdev projects.

- internal reuse allowed
- client delivery allowed when bundled in project work
- redistribution not allowed unless approved

## Pro License

Used for paid kits and starters.

- commercial project usage
- no resale as a competing kit
- updates according to paid plan

## Enterprise License

Used for private clients and organizations.

- private registry access
- custom components
- client-specific theme packs
- support agreement
- migration guidance
- optional SLA

## License Boundaries

Keep licenses separate from source code decisions:

- package names stay stable
- distribution channel controls access
- docs explain what each tier includes
