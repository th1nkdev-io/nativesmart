# Support Model

Nativesmart support should evolve in tiers.

## Internal Support

For Th1nkdev teams:

- architecture guidance
- component usage help
- starter setup
- bug triage

## Pro Support

For paid kits and starters:

- integration guidance
- update notes
- priority bug review
- template customization advice

## Enterprise Support

For private clients:

- dedicated setup
- API integration support
- custom branding
- private package access
- migration planning
- monthly maintenance
- future SLA

## Future SLA Ideas

- response time by severity
- hotfix policy
- supported version window
- private escalation channel
