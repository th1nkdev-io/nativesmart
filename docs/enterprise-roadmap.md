# Enterprise Roadmap

This roadmap prepares Nativesmart for a quasi SaaS/enterprise future without building a SaaS now.

## Near Term

- stabilize priority kits
- add premium starter demos
- add private registry dry run
- document support and licensing
- add migration guides

## Mid Term

- package pro kits separately
- add private documentation section
- add license metadata
- add visual QA snapshots
- add client theme packs

## Later

- private registry UI
- customer portal
- license key management
- billing
- component analytics
- token dashboard
- Figma sync
