# Fintech Mobile App Starter

Premium starter for wallet, transfer, KYC and receipt-driven products.

## Includes

- typed navigation shell
- auth entry screen
- wallet dashboard
- transaction details and receipt states
- Nativesmart theme
- fintech components and screens
- mock API layer
- error and offline states
- API structure
- customization guide

## Starter flow

1. `AuthScreen` captures the phone-first login entry point.
2. `WalletDashboardScreen` shows balance, offline status and recent transactions.
3. `TransactionDetailsScreen` renders a receipt-ready transaction state.
4. `mockApi` centralizes sample data and simulates async product calls.
